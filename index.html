Interfaces Web

A disciplina de Interfaces Web aborda os principais conceitos necessários para desenvolver páginas Web.

Durante a disciplina são estudadas tecnologias como HTML, CSS e JavaScript, permitindo criar páginas estruturadas, funcionais, responsivas e visualmente apelativas.

O objetivo é compreender como estruturar conteúdos, organizar elementos e criar interfaces que possam adaptar-se a diferentes dispositivos.
